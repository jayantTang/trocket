Trocket 支持

Trocket 是在本地运行的网络代理客户端，需使用者自备订阅链接；应用不提供任何服务器或节点。

常见问题

开启开关后无法访问网络
先在应用内执行「测速」。若存在带有延迟数值的线路，选中该线路后重新连接；若全部线路均无延迟数值，说明订阅节点不可用、已过期或超出流量配额。
如何提交问题
进入「菜单 → 诊断日志」，点击「一键拷贝全部日志」，将日志内容提供给订阅服务商或技术支持。日志仅保存在设备本地，可在该页面清除。
是否收集个人数据
不收集。订阅链接、节点配置与日志均只保存在设备本地，详见隐私政策。
国内网站也要走线路吗
不需要。默认「规则」模式下，国内域名（如 .cn 站点、国内常用网站）与国内 IP 直连，其余流量走所选线路；规则库随应用内置，离线可用。若希望全部流量都走线路，在「菜单 → 路由模式」里切到「全局」，切换立即生效、无需断开重连。
连接后部分应用不可用
「规则」模式下国内与局域网流量直连、其余走线路。若个别应用异常，可先在「菜单 → 路由模式」切到「全局」对比：全局下仍异常，说明与所选线路或服务商有关；全局下正常而规则模式下异常，多半是该应用的目标地址被判成了国内，可在诊断日志中查看对应连接记录。
